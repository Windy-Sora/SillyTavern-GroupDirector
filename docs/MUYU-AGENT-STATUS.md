# 暮羽 Agent 当前能力与边界

本文汇总已接入的能力，不作为开发日志、测试成绩单或发布记录。具体参数、来源权限与保存语义以链接的模块合同及源码为准；工具是否可用还取决于宿主端口、用户设置和当前任务。发布状态请查 Git 提交与远端，历史验收见 [TESTING.md](TESTING.md)。

## 已接入的能力

| 领域 | 可用能力 | 关键边界 |
| --- | --- | --- |
| 对话与模型 | 独立接口或复用酒馆连接，思考回传、按需工具组、澄清与授权续接 | 不恢复历史批准；模型文字不能代替操作回执 |
| 配置与选择策略 | 已登记全局字段读取、契约查询、单份草稿、受限整单、可复用配置档；GD 世界书选择与档案库加载策略 | 保存配置档不等于应用；特殊副作用字段不能混入普通整单 |
| 用户 Provider | 源码读取、创建、合成测试、导入、精确替换及删除；已注册版本的真实 render | 系统及非用户来源不可改；测试、导入、真实执行分别核验，代码执行不是沙箱 |
| 脚本与自定义 Agent | 定义管理、导入预览及受控试跑／执行 | 保存定义不授予执行权限；真实执行可能产生副作用与额外费用 |
| 自定义 Prompt 与资源库 | Prompt 条目管理与受限批量；档案、NPC、蓝图库管理、当前聊天存包与指定版本应用 | 库保存与聊天应用分开；聊天及全局模板保存可能部分完成 |
| 当前聊天业务数据 | 变量定义和值、角色记忆、档案、NPC、蓝图节点及结构／进度、导演账本编辑；手工追加记忆、新建缺失档案／NPC、首次空白蓝图 | 使用各自精确差异和版本；不能视为任意 chat_metadata 写入 |
| 业务模型生成 | 记忆提取、标准缺失档案生成、NPC 试生成／追加；受限生成整单 | 生成目录读取不批准执行；最多 8 步受控生成，不是任意工作流 |
| 酒馆资料 | 聊天、角色、世界书、预设、Persona、扩展目录等固定来源；可选本页诊断和提示词构建快照 | 目录、正文、运行值、最终请求分开；构建事件不证明最终发送或注入 |
| 酒馆资源编辑 | 世界书及条目管理、全局／聊天绑定；角色卡创建、复制、指定文本、显示名及受限删除；聊天补全预设复制、保存、指定字段修改与激活 | 仅模块登记的操作；保护当前编辑器草稿，非跨客户端原子事务 |
| Skill | 独立文档包、启停、导入导出、GUI／Agent 管理、按需发现与完整加载 | 内置原件只读；任务固定版本，加载不增加工具或授权 |
| 历史与上下文 | 会话侧栏、导入导出、多种存储后端、原文检索、手动／可选自动摘要 | 原始记录与模型上下文分开；不压缩活跃工具／思考轨迹 |
| 用户笔记 | 独立长期记忆的管理与有界检索 | 与 GD 剧情记忆不同，不是自动学习或自动偏好注入 |
| 中断恢复 | 普通配置及受限整单检查点、本地核对后重新批准剩余步骤；符合条件的普通配置撤回预览 | 不自动续跑／回滚；未知结果不依据当前值推定已保存 |
| 可选服务 | 服务端私有历史、Brave 搜索、诊断、指定目录文档读取、公共文本网页、受限工作区文档预览写入和 JSON 检查 | 需安装、能力检测及相应开关／权限；缺少服务不影响基础对话 |

## 保留边界

- 按用户决定不接入 ST 消息编辑／删除、蓝图模型生成／续写。蓝图已有文本、结构、进度编辑仍保留。
- 档案业务生成只支持模块规定的标准 Schema 与缺失保存；NPC 生成保存不创建／导入 ST 角色卡。独立角色卡工具不能据此理解为 NPC 自动导入流程。
- 变量整仓导入、三库通用批量、任意跨编辑器整单、Provider 改名／持久版本档案／一键撤销未作为通用能力开放。
- 无有效运行消费者的 memoryTokenBudget、llmJsonSchemaHint、档案库仅姓名匹配选项不开放无效写入。
- 暮羽自身连接／密钥、预算／指令、私人存储、内部版本和 Provider 引用表不属于任意业务字段写入口；业务连接 agentConfigs 也不能由普通配置工具修改。
- Capability 编写／修改／独立直接执行、通用 Shell、任意文件系统及 ST 核心修改不在范围。可选服务工作区只允许其专用文档操作。
- 授权 Provider 代码可能产生页面副作用；没有专用消息编辑工具，不等于代码绝不可能修改消息。

## 如何核对范围

普通字段查 [配置契约](../muyu/config/README.md)、[字段注册表](../muyu/config/registry.js) 与 [覆盖检查](../muyu/config/coverage.js)。覆盖分类中的 pending 不等于待开发任务：可能是内部设置、无消费者字段或需要专用编辑器的资产。不要用旧测试时的字段数量推断当前全部配置均可写。

能力、工具与动作须同时通过 [联合装配](../muyu/modules/ASSEMBLY.md) 和 [动作装配](../muyu/actions/ASSEMBLY.md)。可选服务另有 [能力门控](../muyu/services/README.md)。配置、数值变量／脚本定义整单与生成整单各有独立合同，不能任意混用。

普通写入经预览与精确批准；阅读全开不批准修改，全权限仍检查意图、目标、版本、开关和预算。只读方案批准不授予写入。取消不证明已发出的保存被撤销，保存未知不自动重试。

## 验证范围

确定性测试验证合同和状态机，合成宿主加真实模型验证特定题目行为；两者均不能替代目标 ST 版本中的接口、持久化和真实 GUI 验收。具体记录见 [测试文档](TESTING.md) 与 [Skill 评测记录](../muyu/skills/EVALUATION.md)，其中日期及数字只代表当时基线。

后续验收应覆盖普通／拒绝／阅读全开／全权限、切聊天、连接变化、面板重建、保存未知、生成取消与物理排空、手机键盘及中英文。新增能力需另行确定范围，不从旧阶段的“下一轮”恢复已跳过任务。
