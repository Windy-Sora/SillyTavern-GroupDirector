# 世界书与酒馆资料核对

先完整读取 references/workflow.md。先分清 ST 绑定／激活、资源库正文和 GD 读取选择，避免用一个开关解释所有世界书路径。

按资料目录和 readHint 阅读元数据、必要单书或条目。目录有书不等于模型看到了条目；关键词和绑定也不能证明实际注入。用户只问一条设定，不读取整个库全部正文。

GD 选择与 ST 资源编辑是两个独立范围。世界书条目的增删改、创建空书、复制书，以及酒馆全局激活列表／当前聊天绑定和无已知引用的整书删除，可用专用工具精确预览；共享资源会影响其他聊天。角色／Persona绑定、整书重命名和预设写入尚未开放。没有公开的读取能力明确说明，不虚构后台日志和最终 Prompt。

用“世界书来源”“手动选择的世界书”“角色绑定”等真实界面词；字段名仅辅助定位。结果区分本次观察、缓存可能性、已知状态与未知注入。
