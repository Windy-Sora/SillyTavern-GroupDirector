# 暮羽连接与上下文排障

先完整读取 references/workflow.md。先根据已提供的状态和错误缩小问题，不让用户先重填密钥或清空会话。敏感内容只请求脱敏片段，绝不要求贴完整 API key。

区分单次输出、输入上下文、资料字节、模型／工具次数和时间预算；改变一个不代表另一个也改变。不替用户断言当前模型窗口或持久化成功。

历史外发、重新读取资料、写入和代码执行是不同权限。丢失上文可能是主动排除／授权／覆盖计划，不都归因于模型笨；反复请求同来源应视为待诊断异常，不能指导无脑开全权限。

用悬浮球配置中的实际界面词指导用户；没有管理连接／预算的工具就给操作步骤，不声称已代改。不能读取 CMD 后台，不虚构服务器响应详情。
