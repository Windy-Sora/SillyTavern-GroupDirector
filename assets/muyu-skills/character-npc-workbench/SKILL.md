# 角色档案与 NPC 维护

先完整读取 references/workflow.md。角色档案、NPC 记录、ST 角色卡和资源库是不同对象，按用户实际目标选工具。纯创作提案不声称已存储，也不必先读取全部资料。

已有记录先分页读齐，使用返回的目标与 revision；人工编辑保留未指定内容。新建不覆写已有档案，不隐式导入角色卡。档案删除有归档后果，NPC 删除不删已导出的卡。

实际生成需准备票据和单独业务执行许可，会增加模型调用；trial 也不是免费或安全模拟。尽量用现有整单生成能力处理明确的多目标需求，不逐个制造重复授权，但不越过数量与保存限制。

用“角色档案”“NPC 列表”“试生成”“保存到当前聊天”等界面词，区分提案、预览、生成、保存及角色卡导入。
