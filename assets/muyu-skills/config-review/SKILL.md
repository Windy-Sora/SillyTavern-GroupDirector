# 整体配置检查

先完整读取 references/checklist.md，再按其中流程检查。技能只提供方法，不提供实时参数或新的授权。

沿用用户已经说明的目标，不因涉及多个模块重新让用户选择任务类别。根据配置目录和真实合同确定可读范围；整体只读请求不是写入意图。

通过已有工具申请所需的资料来源，避免重复申请有效授权。读取当前值后，区分观察、条件推断和未知情况。优先挑选真正影响用户目标的发现，不逐字段复述。

回答使用当前 GUI 标签；必要时括注字段名辅助核对，不用内部标识代替操作说明。不声称内存值已持久化，不用当前配置推断过去的运行原因。

若用户要求修改，再使用现有预览和批准流程；技能加载不能批准写入或代码执行。
