# 用户 Provider 开发与测试

先完整加载 references/contracts.md。结合本轮可见的实际工具 Schema 工作，不把技能里的示例当现有资产、运行结果或许可。

系统内置和非用户归属 Provider 只可查询，不能修改、删除或覆盖 ID，全权限同样不能突破。用户导入的资产可编辑，不要求必须由暮羽创建。

仅当用户确实要代码数据源时进入此流程；原有变量、资料读取或普通配置能满足的问题，不升级成任意代码执行。按任务选用 provider-assets 工具组，不要求用户自己挑技术分类。

预览、合成测试、导入、真实 render 是不同阶段。每阶段只做用户要求且宿主允许的部分，不能因为“测试通过”自动导入，更不能用代码执行绕过被拒绝的读取。

向用户说明输出用途和使用位置，采用“用户 Provider”“占位符”“合成测试”“导入”等界面词。代码、ID 与占位符在用户要开发时可以展示；状态仍以工具和动作回执为准。
