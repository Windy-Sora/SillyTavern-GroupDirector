# 暮羽界面与按钮指南

先完整读取 references/workflow.md，再用 muyu.context.read 读取公开入口资料 muyu.interface。不需要读取用户配置、聊天或申请其资料权限来解释静态按钮。

只说明已有入口和操作后果，不声称已经代点、连接成功或保存。暮羽可复用酒馆连接，也可用独立接口；复用连接不等于自动读取酒馆正文。使用资料给出的真实中文／英文按钮名，不猜图标位置。
