# 暮羽聊天界面布局

## 英语显示边界（2026-10-06）

`catalog-labels.js`仅提供GUI展示译名：18个内置Skill的名称和用途在英语列表、搜索、只读编辑器与输入框选择器中显示英文，支持原名和译名检索。Skill包、正文、参考文件、revision、ID和模型目录不变；未知内置项回退原文，用户技能不翻译，复制／导出仍使用原内容。只读正文旁明确提示保留原语言。

授权卡、有效授权列表、历史授权恢复菜单和历史外发提示按界面语言投影来源标题；协议及历史记录继续使用原始中英标题，不能借语言切换改变来源或决定。Markdown截断提示跟随面板语言，不翻译对话正文；未传语言的旧调用保留兼容提示。语言重建仍保留草稿和当前视图，不启动业务或模型请求。

## 产物与回执呈现装配（2026-10-06，优化D第九轮）

`artifact-views.js`声明27类现有产物的双语标题、布局和渲染器；`artifact-view-registry.js`验证精确kind、动作所有者、重复项、缺失动作呈现和只读卡边界。面板只负责位置／折叠状态／会话结构，内容与原审批按钮由专用渲染器负责。任务方案和报告仍锚定来源Run，以details呈现；草稿仍在原位置，不因本轮移动卡片、增加控件或修改CSS。

报告无写入动作，任务方案只批准读取；25类动作产物须对应既有action描述，不能默认回落配置应用。未知产物仅提示不支持，不提供重新校验／应用按钮，不阻断其余卡片。渲染不触发模型、业务保存或资料授权；按钮继续调用原controller方法和act包装。

`receipt-presentation.js`明确旧无version及v2–v34的GUI技术详情策略。只有配置回执保留解释／核对快捷入口及原权限、忙碌、只读、历史外发门禁；整单只展示settings子步的配置技术差异，配置档保存只展示原始字段。未知版本仅提示，不进入配置diff格式化。回执文本、持久化schema、来源授权和模型解释仍沿用actions/receipts，不由GUI推断结果或当前值。

报告／方案默认折叠、审批后折叠、同版本用户展开选择、迟到toggle保护、授权自动滚动和面板卸载订阅行为保留。面板dispose不清会话证据／动作租约。中英文及离线DOM已回归；真实320／400／600／800px视觉、键盘及宿主界面验收未执行，不能将离线通过当作视觉验收完成。

## 酒馆连接与独立接口（2026-10-05）

模型连接页新增“连接来源”。选择“使用酒馆当前连接（推荐）”时收起独立地址、密钥、模型菜单及思考设置，显示当前服务商／模型／目标、明确兼容范围和“测试酒馆连接”；模型在酒馆界面选择。测试只发固定消息，不读取聊天、不自动启用，切换来源或卸载面板会取消探测。选择“使用暮羽独立接口”仍使用原表单、模型目录和可选密钥保存。选择本身不连接、不发送，点击“启用此连接”才切换；首次无独立记录且宿主支持时可自动就绪。禁用不删除独立密钥，旧用户设置不强制迁移。

两种模式都显示实际接收目标并遵守资料授权；酒馆连接变化会清除旧任务／授权并提示重新启用。前端包即可复用酒馆已有模型后端，无需为此安装附属插件。发布前仍需真实浏览器手动验收；当前已补离线协议、生命周期、设置回滚及中英文表单测试。

## 当前对话操作菜单（2026-10-03）

## 历史状态、导航与报告收尾（2026-10-02）

历史设置显示实际后端（浏览器 IndexedDB／酒馆账户设置／服务端私有文件／仅本页），与聊天栏复用保存状态文案；设置偏好待刷新生效时仍显示当前实际位置。容量恢复、冲突和待迁移提示保留，仅内存后端不显示持久化成功。

返回按钮和分类导航固定，分类正文各自滚动；当前面板实例内分别记住滚动位置，普通切页和关闭后重开恢复，重建实例不持久化这些位置。快捷入口在显示目标页后展开并定位：接口表单、搜索密钥、有效授权区。快捷定位优先于旧位置，后台渲染不恢复位置或抢焦点；新授权卡自动退出设置时也记录当前位置。

排查报告使用默认收起的原生 details，放在其 sourceRunId 对应回复后；无对应消息的兼容报告收在历史开头，避免持续占据对话尾部。当前面板内按报告及修订保留手动展开状态，修订后重新收起，已移除卡片的迟到 toggle 不覆盖当前状态。原报告内容及前往设置入口保留。连接卡片移除单独的混色背景，与其他设置卡片共用底色和12px圆角。

面板回归覆盖上述状态、滚动和折叠行为。用户已完成上一版实际界面验收并反馈报告位置及连接背景；本轮新增视觉调整仍需用户确认，不把 DOM 替身测试计为像素验收。

## 设置反馈与纠错（2026-10-02）

`form-feedback.js` 统一运行预算、上下文、搜索与连接草稿的就地状态。编辑显示未保存/未启用，保存时锁定该组字段和操作，失败保留输入并允许重试；普通进度刷新不覆盖未保存的预算/搜索草稿。预算更新注明下次任务生效，不声称独立核验磁盘持久化。行为偏好沿用控制器草稿，保存失败提示移到本组，保存期间禁止编辑。

数值错误依据控件的合同范围提示，保存时展开祖先折叠区并聚焦、滚动至第一个无效字段；使用 `aria-invalid`/`aria-describedby` 关联提示。只在用户发起校验时定位，后台刷新不抢焦点。连接预检复用模型连接校验，支持同地址已保存密钥留空，错误不展示密钥；当前启用模型/地址单独展示，编辑与测试不改变当前连接。模型目录选择更新草稿提示，启用期间取消旧探测并锁定目录操作。

自动整理历史开关直接可见，摘要预算等细项仍折叠；输入预算的估算和迁移说明单独折叠。原默认值、保存入口和授权合同不变。关闭设置仍清空未提交密钥，其他表单草稿按原挂载生命周期保留。

## 入口层级

技能配置采用目录／详情／导入三种互斥视图。目录按用户与内置分组，内置默认收起，搜索临时展开匹配组；点名称直接进入详情。详情正文／参考文件／高级设置用页签切换，不销毁编辑DOM。返回目录后通过“继续未保存编辑”恢复草稿，替换与重载仍需原有确认。内置技能显示只读文本，可复制后修改；低频导入、刷新、帮助及单项复制、导出、删除收进不挤压布局的不透明菜单。技能列表不再独立限高滚动，沿用设置页滚动容器。

- 对话：历史/当前会话操作 → 默认收起的会话工具 → 消息 → 状态、任务、输入与发送。
- 会话工具：当前资料授权及配置入口、本轮开销、历史摘要预览/整理/清除、本次不携带旧历史。展开区独立限高滚动，不把长统计塞进输入框区域。
- 齿轮配置：模型连接、资料与权限、对话与显示、上下文与预算、存储与记忆、技能与工具。一次显示一组；窄容器两列导航，460px起三列两行。分类仅隐藏既有编辑器，保留草稿、滚动与处理器。
- 模型连接：服务地址、模型、密钥、默认开启的“记住密钥/下次自动启用”及明文存储风险说明、思考模式、启用/禁用、窗口重置。未连接时发送会提示并进入本页，返回后未发送消息仍在。
- 资料与权限：诊断/聊天/扩展资料授权、撤销后果、危险全权限模式。
- 对话与显示：补充指令启用、编辑、保存/放弃/恢复默认、执行过程显示档位、窗口重置。显示偏好立即生效，补充指令从下次发送生效。
- 上下文与预算：调用/工具/时间/输出/资料预算，以及输入预算、保留问答数和自动摘要策略，保存后下一轮生效。
- 存储与记忆：对话存储位置、自动保存、保存错误和重试、暮羽长期记忆；账户存储位置仍按原合同在刷新后切换。
- 技能与工具：技能目录与编辑、联网搜索配置；未连接的小地球仍引导到模型连接，缺搜索密钥引导到本页搜索表单。

执行过程显示存储于账户插件设置的`muyuDisplayConfig`，默认compact，不外发模型、不改变权限或预算、不随剧情配置档导入导出。compact保留最后阶段与失败记录；standard展示完成阶段；detailed增加全部阶段、序号与耗时；verbose再显示资料计数与技能版本/路径。切档重用过程节点、保留展开状态，不修改原始记录。失败/拒绝标记始终在过程摘要可见，授权与操作回执独立显示。共享表单状态采用ready/dirty/saving/error，行为及技能编辑器也采用同一视觉状态，保存失败保留输入，不把“已更新”冒充落盘确认。

上下文预算内另有“已有对话外发”选择：自动允许（默认）／逐次审批（授权失效时确认）。文案明确旧问答可能引用敏感资料、会发送给当前模型服务，包含换连接后的历史；不授予新的宿主资料读取、配置写入或代码执行权限。保存后生效并持久化，恢复默认上下文预算保留已保存的外发策略，“本次不携带旧历史”优先。审批模式的输入框内确认入口继续保留。

## 聊天区与左侧历史栏

插件设置面板暂时固定使用经典界面，隐藏新版导航选择器并忽略已保存的新版布局偏好；新版实现保留在代码中。移除顶部帮助和打开聊天按钮，使用“工具 → Agent 配置 → 显示暮羽悬浮球”控制入口，默认显示，保存到插件设置。隐藏入口不关闭已打开的窗口、不停止任务，可在同一位置重新开启。

插件配置差异使用 `config-diff-view.js` 展示现有界面名称、所在功能区和易读值。草稿、整单设置部分及配置档都默认隐藏原字段 ID；原生“技术详情”保留完整原值，长 Prompt 在摘要里明确标为截断。回执沿用同一映射并保持历史结果与保存确认语义，变量差异仍按变量自身契约显示。显示映射不改变确认按钮、批准版本、写入或权限协议。

任务方案使用原生 `details/summary`，优先放在产生该方案的助手回复之后，而非始终堆在聊天末尾；没有对应消息锚点的兼容产物保留在末尾。待批准方案默认展开，已批准、拒绝或失效的方案默认收起，摘要保留目标，展开后仍可查看步骤与风险。当前挂载实例内保留手动展开状态；方案修订或审批状态变化重新采用默认状态。已显示的方案只是规划时的记录，不声称后续资料尚未读取；实际结果以之后的回复和回执为准。折叠、展开、重绘不触发授权或模型调用。

用户消息保留右侧气泡；助手回复采用开放式正文，供长文、代码和表格使用。输入与底部任务/发送工具栏合成圆角卡片，保留 Ctrl+Enter 发送、Enter 换行，不引入新的模型能力或自动授权。

浮窗默认收起历史。打开后，在基础窗口至少460px且视口能容纳额外240px时，向左增加240px侧栏并保留聊天宽度；靠近左边缘时整体平移以留在屏幕内。扩展期间最低总宽700px；收起恢复聊天宽度，拖动仍以整个可见窗口为边界。进入配置临时释放侧栏空间，返回聊天恢复，关闭和卸载释放空间。外壳向视图注入 `setSidebarOpen`，旧挂载实例不能改变新窗口，不将业务状态交给外壳。

容器不足680px时，历史是独立列表页，不叠盖聊天：返回聊天、选中会话或新建会话后切回。足够宽时使用240px历史栏与聊天的双列。经典内嵌面板无法向宿主外扩展，也使用上述容器自适应规则。列表页、配置页与聊天共用原有 DOM，切换不丢失输入，不自动发送。

配置页内编辑器默认展开，不要求用户进入分类后再找折叠入口。权限与存储风险说明贴近对应控件，不隐藏授权后果。

## 状态约定

澄清阶段新增消息区内的问题卡：选项只填充回答草稿，自由回答后点“回答并继续”；等待时普通发送禁用，可取消澄清。问题文本安全展示；重建面板由应用快照恢复草稿，切聊天使旧问题失效，刷新后历史不恢复可操作卡片。等待时气泡状态为需关注，见 [交互合同](../interactions/README.md)。

分类切换仅隐藏已有 DOM，不重建编辑器、不保存、不授权、不启动请求。进度通知仍遵守各编辑器原有草稿契约。返回聊天会清空未提交密钥，其他编辑不自动保存；重新打开齿轮保留当前挂载实例的分类。配置连接快捷入口固定进入连接页，资料授权入口固定进入资料与权限页。
