# 暮羽可选服务端插件

2026-10-09 第二轮（服务0.3.0）：新增 `diagnostics.cjs`，加载后仅在内存记录服务自身的历史／搜索／存储自检失败；每账户最多200条、30分钟，全局最多256账户／4096条，容量压力可能提前淘汰。重启清空，不写磁盘，不收集酒馆全局Console或CMD。缺失身份不归入默认账户。

记录只有事件序号、时间、闭合操作／阶段／错误分类、耗时和可选HTTP状态，不含路径、账户、会话ID、搜索词、正文、密钥、原始异常或响应体。分类不是具体根因证明，空记录不证明从未失败。用户取消的搜索不作为网络错误记录。

- `GET /service/diagnostics`：当前宿主账户保留记录。
- `POST /service/diagnostics/clear`：只允许 `{ confirm: true }`，仅清空当前账户记录，不删除对话；之后新错误继续记录。
- `serviceDiagnostics`：接入暮羽既有Provider只读来源／资料授权，账户级global范围；空选择器读概况，`recent:N`（1–50）读近期事件。只读工具不能清空；旧版／服务缺席时停止，不换来源绕行。阅读全开与全权限遵守现有策略。

齿轮→存储与记忆→可选服务→“服务错误记录（最近30分钟）”可本地查看、导出JSON和清空；这些点击不调用模型、不授予模型读取权限。更新全部.cjs（含diagnostics.cjs）并重启酒馆。

2026-10-09 可选服务管理首轮：新增 `service-status.cjs`，部署时需与其他 `.cjs` 文件一起更新并重启酒馆。`GET /service/status` 返回闭合版本、能力与历史容量；要求有效宿主账户目录，不返回路径、账户标识或密钥。旧 health、历史及搜索接口保持不变。

齿轮→存储与记忆→“可选服务 · 文件历史与联网”为统一安装／检查入口，搜索与对话存储提供直达。检测不调用模型或Brave；404再检查旧health，区分旧版与未发现服务，不能区分未安装／未启用／未重启，不禁用旧版原有功能。

主动点击“测试历史存储（写入临时文件）”才发送 `POST /service/storage-check`，正文只允许 `{ confirm: true }`。在已认证账户私有 history/.service-probes 下创建独立随机目录，写入、读回、清理；不修改真实对话，空父探测目录可能保留。权限／空间／清理失败返回脱敏阶段与错误，清理失败不报告通过。每账户同时一次，全局最多256账户；浏览器等待10秒，停止等待不保证文件操作撤销，服务端继续清理。通过不证明已有对话已保存、未来写入、磁盘剩余容量、搜索密钥或其他酒馆功能。

2026-09-30 大上下文容量更新：每命名空间仍最多 64 会话；每会话最多 4096 条消息、32 MiB，合计 256 MiB，单条模型文本最多 2 MiB 序列化 UTF-8。容量不是默认注入量。旧记录格式不迁移；使用更大存档需同步更新服务端并重启 ST，旧服务端仍会按原容量拒绝保存，不静默分叉或删减记录。

此目录只包含服务端插件代码，绝不放真实聊天记录。ST 会把前端扩展目录作为静态资源提供；私密历史不能写入这里。

2026-10-09：兼容酒馆提供的相对用户目录（如默认 `dataRoot: ./data`），按酒馆进程工作目录解析；仍只使用宿主认证用户的目录，不接受请求指定目录或缺失身份时回退默认账户。更新 `index.cjs` 后必须重启酒馆，刷新前端不能重载服务端代码。健康检查成功只证明路由加载，不代表对话文件读写成功。

将本目录全部 `.cjs` 文件安装到 SillyTavern 的 `plugins/gd-muyu-history/`，在 ST 配置中开启 `enableServerPlugins`，重启 ST。服务端按已认证账户写入 `<ST data root>/<user>/.group-director/muyu/history/<namespace>/<conversation-id>.json`；不会写入聊天存档或角色卡。文件未加密，备份与磁盘访问仍需由用户管理。

浏览器端优先使用该后端；服务端插件缺席时回退 IndexedDB。首次连接会复制浏览器中尚未存在于文件后端的旧会话，不删除浏览器原件；相同 ID 的文件记录不会被覆盖。无法联系已启用的后端时显示错误，不静默切换以免产生分叉。持久化仅包含受限的会话 DTO，不保存 API 密钥、授权、可恢复的执行句柄或完整工具日志。结构借鉴 Codex 的独立存储边界和按需恢复思想，没有复制其代码或引入完整 JSONL 事件日志。

删除会话时以仅含 ID 的删除标记原子替换原文件，移除会话正文并释放活跃记录容量；后续连接不会从保留的浏览器备份重新迁入同 ID。并发迁移以已存在的服务端记录为准。DTO v7 支持问题来源标记；使用此版本前端时需同步更新本目录的服务端文件并重启 ST。

2026-09-30 新增可选网页搜索路由，由 `web-search.cjs` 独立实现。原插件 ID 和历史API保持不变。搜索仅在用户开启小地球时使用，Brave API Key 从该次请求接收且不写盘、不回显；仅请求固定 HTTPS 搜索端点，不抓取返回网页。部署更新需一起复制 `web-search.cjs`。配置与边界见 [联网搜索](../web/README.md)。
